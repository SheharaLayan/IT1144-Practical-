Switches



Cisco Catalyst 9300 Series


The Cisco Catalyst 9300-24T is a high-performance Layer 2/3 enterprise
switch featuring 24 data-only ports. It is engineered for secure branch networks, offering advanced support for segmented Virtual LANs (VLANs), high-speed 802.1Q trunk lines, and enhanced network security configurations like hardware-anchored Access Control Lists (ACLs).




Routers





Cisco ISR 4000 Series


The Cisco ISR 4331 is a modular enterprise-grade network router designed to handle high-performance routing, security firewalls, and network automation across medium-sized corporate offices. It supports advanced features like Intelligent WAN (IWAN), integrated security encryption, dynamic IP allocation, and scalable network expansion modules.
