Cisco Routers

What can you do with this device?

    Routers operate at Layer 3 (Network Layer) of the OSI model. Their primary purpose is to join completely different networks together (such as connecting your school's private LAN to the global Internet).


  • Routing Table: Routers read destination IP Addresses (instead of MAC addresses) and consult internal routing protocols to select the single fastest, most efficient pathway across different regional networks.

  • Inter-VLAN Routing: Because switches isolate VLAN networks from one another completely, a Router (or Layer 3 switch) is required to act as a default gateway so users on VLAN 10 can safely talk to users on VLAN 20.

  • Network Services (DHCP & NAT): DHCP Server: Automatically assigns IP addresses, subnet masks, and DNS servers to host devices so network administrators don't have to type them in manually.

Terminal Running Configuration

Live terminal structure for the node:

Terminal - Cisco Enterprise ISR Router
Router> enable
Router# configure terminal
Router(config)# hostname CentralRouter

! -- IP ADDRESS CONFIGURATION --
CentralRouter(config)# interface gigabitEthernet 0/0
CentralRouter(config-if)# description Connection_to_LAN
CentralRouter(config-if)# ip address 192.168.1.1 255.255.255.0
CentralRouter(config-if)# no shutdown
CentralRouter(config-if)# exit

! -- INTER-VLAN ROUTING CONFIG (SUB-INTERFACES) --
CentralRouter(config)# interface gigabitEthernet 0/0.10
CentralRouter(config-subif)# encapsulation dot1Q 10
CentralRouter(config-subif)# ip address 192.168.10.1 255.255.255.0
CentralRouter(config-subif)# exit

! -- DHCP SERVER POOL CONFIGURATION --
CentralRouter(config)# ip dhcp pool LAN_USERS
CentralRouter(dhcp-config)# network 192.168.1.0 255.255.255.0
CentralRouter(dhcp-config)# default-router 192.168.1.1
CentralRouter(dhcp-config)# dns-server 8.8.8.8
CentralRouter(dhcp-config)# exit

! -- DYNAMIC ROUTING SYSTEM SETUP (OSPF) --
CentralRouter(config)# router ospf 1
CentralRouter(config-router)# router-id 1.1.1.1
CentralRouter(config-router)# network 192.168.1.0 0.0.0.255 area 0
CentralRouter(config-router)# network 192.168.10.0 0.0.0.255 area 0
